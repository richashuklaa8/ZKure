# Project provenance and development disclosure

This repository is assembled from the team's supplied ZKure prototype archive and supporting project materials. The prototype archive contained an earlier internal name, MediProof; ZKure is the public project identity.

Do not imply that the contents of the supplied archive were newly authored during the Hack-a-Sol event. Follow the event's originality rules: disclose pre-existing scaffolding and third-party components accurately, and ensure all code claimed as hackathon-built was written during the permitted period.

AI coding assistance must be disclosed in the submission. Team members should review and be able to explain every submitted component.
